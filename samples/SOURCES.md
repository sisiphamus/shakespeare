# Sample sources and licenses

Shakespeare ships **real human writing** as style exemplars. Each file has a YAML header with source + license. Summary:

| Category | Source | License / notes |
|----------|--------|-----------------|
| **academic** | PLOS Open Access papers via api.plos.org | **CC BY 4.0** — attribution required; DOI in each file |
| **narrative** | Project Gutenberg *Modern Essays* (ebook 38280) | **Public domain (US)** |
| **fun** | Project Gutenberg *Best American Humorous Short Stories* (10947); Twain *1601* (3190); NUS SMS excerpts | PD (US) + SMS research corpus attribution |
| **conversational** | Chesterfield *Letters to His Son* (Gutenberg 3361); NUS SMS Corpus (English) | PD (US); NUS SMS free for research — excerpts only, attributed |
| **email** | [Enron Email Dataset](https://www.cs.cmu.edu/~enron/) (CMU distribution of FERC release) | **Public domain** research corpus; ~30 messages sampled across employees |

## Not included (on purpose)

- Copyrighted modern magazine/fashion writing  
- Full republish of NUS SMS or Enron datasets (excerpts only)  
- Any single living person's private mail without a public corpus release
